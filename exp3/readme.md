## 一、实验目的

掌握基于局部特征的图像拼接方法，理解SIFT特征提取、FLANN匹配、Lowe比率测试及RANSAC单应矩阵估计的作用。将一张照片分割成两张有重叠区域的图像，再依据特征匹配恢复原图，并通过窗口截图与数值指标验证结果。

## 二、实验内容

在Windows系统的Conda cv环境中完成实验，使用Python 3.11.17、OpenCV 4.12.0及NumPy 2.2.6。算法在CPU上运行，使用实验三参考代码的核心流程。

原图为1706×1279像素的校园湖景照片。沿水平方向裁剪：左图a保留第0至1103列，右图b保留第592至1705列，高度均保持1279像素。重叠区为第592至1103列，共512像素，约占原图宽度的30.01%。

### 2、SIFT特征提取

先用cv2.cvtColor将两幅彩色图像转换为灰度图，再创建SIFT检测器，分别提取关键点及其128维描述符。关键点用于定位局部结构，描述符用于比较两幅图像中局部区域的相似程度。

```python
gray_a = cv2.cvtColor(img_a, cv2.COLOR_BGR2GRAY)
gray_b = cv2.cvtColor(img_b, cv2.COLOR_BGR2GRAY)
sift = cv2.SIFT_create()
kp_a, des_a = sift.detectAndCompute(gray_a, None)
kp_b, des_b = sift.detectAndCompute(gray_b, None)
```

![图2 左右输入图像的SIFT关键点与特征尺度](./图片/02.png)

图2 左右输入图像的SIFT关键点与特征尺度

本次左图提取到5361个关键点，右图提取到5028个关键点。图中圆圈表示关键点位置与尺度。建筑边缘、树木及前景木板等纹理较丰富，特征点较密集；天空及平滑水面中的特征点较少。

保留足够宽的重叠区可以增加共同特征的数量。仅把原图无重叠地分成两半，往往无法得到足够的共同特征，难以通过本实验的匹配流程估计可靠变换。

### 3、FLANN特征匹配与RANSAC估计

按参考代码配置KD-tree FLANN匹配器，trees=5、checks=50，使用knnMatch(k=2)为左图每个描述符寻找右图的两个近邻。若最近邻距离小于次近邻距离的0.7倍，则保留该匹配，以减少歧义对应关系。

```python
flann = cv2.FlannBasedMatcher(dict(algorithm=1, trees=5),
                              dict(checks=50))
matches = flann.knnMatch(des_a, des_b, k=2)
good_matches = [m for m, n in matches
                if m.distance < 0.7 * n.distance]
```

![图3 OpenCV窗口显示通过比率测试的2112组匹配](./图片/03.png)

图3 OpenCV窗口显示通过比率测试的2112组匹配

匹配图显示RANSAC之前的全部优质匹配，因此仍可见少量交叉或错误连线。随后以右图坐标作为src_pts、左图坐标作为dst_pts，调用findHomography(src_pts, dst_pts, cv2.RANSAC, 5.0)，估计从b到a的单应矩阵。

RANSAC判定其中2091组为内点，剔除21组不符合模型的匹配，内点率为99.01%。实测矩阵如下，水平位移约为592像素：

```text
H ≈ [[ 0.999998638,  0.000000542, 592.000057277],
     [-0.000001753,  1.000001163,  -0.000335977],
     [-2.021027e-9,  8.665863e-10,  1.000000000]]
```

由于两图来自同一原图的水平裁剪，理论变换为x_a=x_b+592、y_a=y_b。该已知偏移只用于验证估计结果，没有参与特征匹配或单应矩阵求解。

### 4、透视变换与图像拼接

将右图的四个角点通过H变换到左图坐标系，合并两图角点范围以计算输出画布。构造平移矩阵T使所有图像坐标可见，对右图执行warpPerspective，再将左图复制到画布对应位置。

```python
stitched_img = cv2.warpPerspective(
    img_b, translation_matrix @ H,
    (x_max - x_min, y_max - y_min))
stitched_img[-y_min:h_a-y_min,
             -x_min:w_a-x_min] = img_a
```
